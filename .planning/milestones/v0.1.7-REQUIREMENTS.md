# Requirements Archive: v0.1.7 Stability & Preact Migration

## Requirements

### Rendering Performance

- [x] **PERF-01**: Streaming updates only patch the last message block instead of replacing all blocks
  Outcome: Adjusted. The shipped runtime no longer uses the old imperative streaming patch path; the active webview moved to Preact/VDOM rendering instead of implementing a narrow legacy patch.
- [x] **PERF-02**: Message list uses virtualization to render only visible messages
  Outcome: Deferred. This was not shipped in v0.1.7 and remains a candidate for the next milestone if real conversation-size profiling shows a need.
- [x] **PERF-03**: Event listeners use delegation instead of re-attachment after renders
  Outcome: Adjusted. The active webview no longer depends on the old manual listener rebinding model; component-owned Preact handlers replaced that runtime path.
